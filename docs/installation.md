# Installation Guide

## Overview

This document describes the deployment process of the monitoring and observability stack on an Ubuntu 26.04 LTS AWS EC2 instance.

The stack consists of:

- Prometheus
- Grafana
- Node Exporter
- Alertmanager

---

# Prerequisites

Before deployment, ensure the following requirements are met:

- AWS Account
- Ubuntu 26.04 EC2 Instance
- Elastic IP associated with the instance
- SSH access to the server
- Security Groups configured for required ports
- Stable internet connection

---

# AWS EC2 Instance Setup

An Ubuntu EC2 instance was launched on AWS and configured as the monitoring server.

After deployment:

- An Elastic IP was associated with the instance.
- SSH access was established.
- The operating system packages were updated.
- Required firewall and security group rules were configured.

---

# Prometheus Installation

Prometheus was installed as the primary monitoring server.

The deployment included:

- Downloading the Prometheus release
- Creating the Prometheus user
- Creating required directories
- Configuring `prometheus.yml`
- Creating a systemd service
- Starting and enabling the Prometheus service

Prometheus stores infrastructure metrics in its built-in time-series database.

---

# Node Exporter Installation

Node Exporter was installed to expose Linux system metrics.

The exporter provides metrics including:

- CPU utilization
- Memory usage
- Disk utilization
- Filesystem statistics
- Network activity
- System load

Prometheus periodically scrapes these metrics for monitoring.

---

# Grafana Installation

Grafana was installed to visualize metrics collected by Prometheus.

The deployment included:

- Installing Grafana
- Starting the Grafana service
- Configuring Prometheus as the data source
- Importing monitoring dashboards

Grafana provides real-time visualization of infrastructure performance.

---

# Alertmanager Installation

Alertmanager was configured to process alerts generated by Prometheus.

The deployment included:

- Installing Alertmanager
- Configuring alert routes
- Configuring Gmail SMTP
- Creating email notification rules
- Enabling the Alertmanager service

Whenever configured thresholds are exceeded, Alertmanager sends email notifications.

---

# Service Management

All monitoring components were configured to run as Linux systemd services.

The following services were enabled:

- Prometheus
- Grafana
- Alertmanager

This ensures that the monitoring stack automatically starts after system reboot.

---

# Verification

After deployment, the following checks were performed:

- Prometheus was accessible through the web interface.
- Grafana dashboards displayed live metrics.
- Node Exporter targets appeared as **UP** in Prometheus.
- Alertmanager was successfully connected.
- Test alerts generated email notifications.

---

# Result

The monitoring stack successfully collected, stored, visualized, and alerted on infrastructure metrics from the AWS EC2 instance, providing a complete observability solution suitable for learning modern DevOps monitoring practices.
