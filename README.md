# Prometheus-Grafana Monitoring Stack on AWS

## Project Overview

This project demonstrates the deployment of a complete monitoring and observability stack on an AWS EC2 Ubuntu instance using Prometheus, Grafana, Node Exporter, and Alertmanager.

The monitoring stack collects real-time system metrics from the EC2 instance, stores them in Prometheus, visualizes them through interactive Grafana dashboards, and sends automated email notifications whenever predefined alert conditions are triggered.

The project was built to gain hands-on experience with cloud infrastructure monitoring, Linux server administration, metrics collection, dashboard creation, and alert management using industry-standard DevOps tools.

---

## Objectives

- Deploy a monitoring stack on an AWS EC2 Ubuntu instance.
- Collect CPU, memory, disk, and system metrics using Node Exporter.
- Configure Prometheus to scrape and store infrastructure metrics.
- Visualize collected metrics using Grafana dashboards.
- Configure Alertmanager to send email notifications when alerts are triggered.
- Gain practical experience with monitoring and observability tools used in modern DevOps environments.
